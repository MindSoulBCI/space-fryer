## 32 通道 EEG

当前只提供明确标注的合成演示数据：32 通道、模拟 256 Hz、最近 2 秒波形、通道切换、冻结波形、RMS/峰峰值、1–45 Hz 五频段归一化功率。频谱使用 Hann 窗 DFT。

专注力仍为模拟输入（低/中/高或随机游走），不是由这些合成 EEG 波形推断。没有连接任何真实脑电设备，也不显示脑健康判断。真实接入需要设备型号、SDK/协议、采样率、通道顺序、数据单位和连接方式。

专注力窗口默认打开，点击“打开 32 通道 EEG 看板”可再次打开看板。EEG 默认位于专注力窗口右侧，需要转头查看，也可用系统窗口功能移动。

## 操作与窗口

- 左侧选料：选择食材，取料、下锅，成熟后 3 秒内捞起，再出餐。
- 中间订单：查看食客要求及剩余时间；可重新打开选料/专注力窗口。
- 右侧专注力：低/中/高为模拟值，模拟断连会冻结游戏。
- 更右侧 EEG：默认展示 32 路合成波形，可冻结和切换统计通道。
- 固定窗口 ID 和 tag；默认间距 120 dp，以订单和专注力窗口为稳定锚点，不随焦点重新排布。
- 用户移动后的窗口不在重组时被拉回。首次取料前不消耗订单时间。
