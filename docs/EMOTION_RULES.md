# 专注力、模拟情绪与烹饪

本版没有真实情绪检测。模拟情绪由用户点选；32 通道 EEG 是合成演示信号，不用于推断情绪。更换设备/接入算法前，不把任何模拟值标成实测。

- 专注力控制火焰高度与基础烹饪速度。
- 情绪值 0=低落、0.5=平静、1=愉快；实际值平滑靠近用户选择，避免突变。
- 情绪系数 = 0.35 + 0.65 × 情绪值。
- 最终烹饪速度 = 原专注力速度 × 情绪系数。
- 同等专注力下，低落 / 平静 / 愉快对应 35% / 67.5% / 100% 速度。
- 情绪不改变火焰大小，不伪造设备连接，也不改变订单倒计时或成熟后 3 秒焦糊窗口。
- 暂停和模拟断连仍冻结游戏；重新开店恢复默认状态。

回归验证包含：相同专注力的速度对比、情绪系数单调性和范围约束、NaN 输入拒绝、模拟连接身份保持。
