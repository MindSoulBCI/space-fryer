# 1.3 登录与游客流程

启动 → 中央 PICO 原生窗口显示登录／注册 → 本机账号进入手动模式，或游客入口进入自动演示。

- 游客自动从全部 40 种食谱中随机选择，订单与所选食物匹配，每 0.7 秒最多执行一步取料、下锅、捞起、出餐或清理。
- 「接管操作」立即关闭自动流程，保留食材、烹饪进度、得分和当前订单；无需注册即可手动体验。
- 暂停／断连／应用不可见时自动流程不会继续推进。重新开店保留当前自动或手动控制模式。
- 未选择登录或游客入口前不加载料理场景，不开启烹饪计时，不接受操作事件。
- 本机账号使用每账号随机盐与 PBKDF2-HMAC-SHA256（210000 次）保存密码校验值。账号文件排除云备份和设备迁移；不保存明文密码、不自动登录、不提供云端账号或找回密码。
- 专注力、情绪与 EEG 仍为模拟输入。

界面沿用 DefaultStage 与现有四个 WindowContainer。登录入口复用 DinerOrders；新增 TextField、Button 使用 PicoTheme 与系统默认玻璃。未新增窗口类型或修改场景资源。
